### 🚛 Embedded Linux & Fleet Management

I also design and develop embedded software for **commercial vehicle and fleet-management systems**.

These systems run on constrained Linux/ARM edge devices installed in trucks and interact directly with vehicle hardware.

Typical topics include:

- Embedded C++
- Linux
- CAN / CAN-FD
- FMS / J1939 vehicle data
- Tachograph and K-Line communication
- GPS and telematics
- Serial communication
- ZeroMQ-based IPC
- SQLite
- Docker / Balena Engine
- OTA software updates
- Health monitoring, watchdogs and recovery mechanisms
- Communication with cloud fleet-management platforms

I work both on the software architecture and on low-level integrations with vehicle and telematics hardware.
